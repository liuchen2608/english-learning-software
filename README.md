# 英语软件开发（Talk Town）

Talk Town 是一款面向近期准备出境旅行、英语基础薄弱成年人的 AI 场景化英语学习产品。

产品不以系统讲授英语知识为首要目标，而是通过真实任务训练，让用户在机场、酒店、餐厅等场景中完成可立即使用的英语交流。当前 MVP 聚焦“咖啡店点餐”任务，验证 AI 场景化训练能否提升用户完成真实交流任务的能力。

## MVP 学习闭环

1. 用户使用中文描述旅行目标与英语需求。
2. AI 解析目标，并在低置信度时继续确认。
3. 系统基于已发布内容生成学习路线。
4. 用户进入咖啡店点餐任务。
5. 依次完成基线测试 A、引导训练 B 和迁移测试 C。
6. 系统输出任务结果并记录能力变化。

AI 负责目标理解、表达判定和学习反馈；确定性状态机负责关键步骤推进。知识内容经过审核、版本化和发布后，通过混合检索与条件 Rerank 为生成过程提供依据。

## 启动网页端

环境要求：Node.js 22.13 或更高版本、pnpm。

```bash
cd talk-town-web
pnpm install
pnpm dev
```

开发服务启动后，按终端提示在浏览器中打开本地地址。

## 当前范围

MVP 包含：

- AI 目标理解与确认
- 已发布场景组成的学习路线
- 咖啡店点餐 A/B/C 训练闭环
- 结果页与匿名学习记录
- 知识摄取、审核、切块、发布、检索与评测规范

MVP 暂不包含：

- 真人语音与发音评分
- 完整多场景训练
- 账户、支付与订阅系统
- 长期 Memory 与通用 Agent
